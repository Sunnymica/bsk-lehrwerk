# Rückmeldung an Claude: Plattform-FAQ

## Übernommen

- durchgehende FAQ-Seite statt künstlicher Reiter
- Merkkasten zur lokalen Speicherung und Gerätebindung
- beruhigender Hinweis, dass die Kursleitung Eingaben nicht live sieht
- freiwillige WhatsApp-Abfrage ohne Mehrheitszwang
- keine Fortschrittszählung und kein `Lehrwerk.abschluss()`

## Geändert

**Teams-Warnhinweis**

- **Korrektur:** Aus „Teams weist auf jede externe Seite immer hin“ wurde „Teams kann beim Öffnen einer externen Website warnen“.
- **Grund:** Das konkrete Verhalten hängt vom Teams-Client und den Einstellungen ab; die absolute Aussage war nicht belastbar.

**Lokale Speicherung**

- **Korrektur:** „nicht im Internet“ wurde durch die technisch genauere Aussage ersetzt, dass die Plattform Eingaben nicht an die Kursleitung oder einen eigenen Server überträgt.
- **Grund:** `localStorage` beschreibt den Speicherort; „nicht im Internet“ ist weiter gefasst und missverständlich.

**Privates Fenster**

- **Korrektur:** Präzisiert, dass die Daten normalerweise nach dem Schließen verschwinden.
- **Grund:** Während einer laufenden privaten Sitzung kann Speicherung durchaus funktionieren.

**Trägerkontakt**

- **Korrektur:** Der rohe Platzhalter wurde in einen gut sichtbaren, aber lesbaren offenen Hinweis umformuliert.
- **Grund:** Die Seite ist integriert, darf aber erst nach Ergänzung der Kontaktdaten freigegeben werden. Der Status bleibt deshalb `in-arbeit`.

## Kleine Auffälligkeit

Der Übergabehinweis nennt elf Fragen; die HTML-Seite enthält dreizehn FAQ-Fragen (3 Zugang, 3 Eingaben, 5 Bedienung, 2 Kontakt). Das betrifft nur die Beschreibung, nicht die Funktion.
