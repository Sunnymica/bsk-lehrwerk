Was mache ich mit der Datei?
  1. Die heruntergeladene Datei muss homework.js heißen.
  2. Bei GitHub im Repo den Ordner data öffnen.
  3. Add file → Upload files wählen und die Datei hochladen.
  4. Committen. Nach dem Pages-Build erscheinen die Hausaufgaben auf der Startseite.

Die Datei im Repo wird ersetzt. Im Code müssen Sie nichts ändern.
