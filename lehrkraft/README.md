# Hausaufgaben-Editor

Der Editor liegt nach dem Hochladen unter:

```text
https://BENUTZERNAME.github.io/REPOSITORY/lehrkraft/
```

Er ist nicht in der Navigation der Lernplattform verlinkt. Die Adresse ist technisch trotzdem öffentlich erreichbar. Im Editor werden keine Passwörter oder Zugangsdaten gespeichert.

## Arbeitsablauf

1. Hausaufgabe im Formular anlegen und mit **Hausaufgabe übernehmen** in die Arbeitsfassung setzen.
2. Bei Bedarf weitere Hausaufgaben ergänzen, bearbeiten, duplizieren, sortieren oder löschen.
3. **homework.js herunterladen** anklicken.
4. Im GitHub-Repo den Ordner `data` öffnen.
5. Über **Add file → Upload files** die heruntergeladene `homework.js` hochladen und die vorhandene Datei ersetzen.
6. Committen und den GitHub-Pages-Build abwarten.

Die Arbeitsfassung wird zusätzlich im Browser gespeichert. **Veröffentlichte Fassung neu laden** verwirft diese lokale Fassung und lädt den Inhalt aus `data/homework.js`.
